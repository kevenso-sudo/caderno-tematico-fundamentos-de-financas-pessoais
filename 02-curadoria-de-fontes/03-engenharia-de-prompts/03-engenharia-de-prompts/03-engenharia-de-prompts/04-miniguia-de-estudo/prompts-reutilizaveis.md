# Prompts Reutilizáveis

## 1. Revisão geral

Com base exclusivamente nas fontes fornecidas, faça uma revisão sobre as finanças pessoais.

Organize a resposta em:

 1. definição;
 2. conceitos fundamentais;
 3. relações entre os conceitos;
 4. exemplos práticos;
 5. aplicações;
 6. pontos que merecem revisão.

 Indique as fontes utilizadas.

---

## 2. Explicação para iniciante

 Explique as finanças pessoais como se estivesse ensinando alguém que nunca estudou o assunto.

 Utilize linguagem simples, mas preserve a precisão conceitual.

 Apresente:

 * definição;
 * exemplo;
 * analogia;
 * conceito relacionado;
 * erro comum.

---

## 3. Comparação

 Compare Poupança e Investimento.

 Apresente:

 * definição de cada conceito;
 * principais diferenças;
 * semelhanças;
 * relação entre eles;
 * exemplo prático;
 * erro comum de interpretação.

---

## 4. Estudo de caso

 Crie um estudo de caso fictício envolvendo as finanças pessoais.

 Apresente uma situação do cotidiano realista e peça que eu identifique:

 1. os conceitos envolvidos;
 2. o problema;
 3. as possíveis causas;
 4. alternativas de solução.

 Não apresente a solução inicialmente.

---

## 5. Teste de conhecimento

 Crie 10 perguntas sobre as finanças pessoais, utilizando exclusivamente as fontes fornecidas.

 Distribua as perguntas entre:

 * conceitos básicos;
 * compreensão;
 * comparação;
 * aplicação;
 * análise.

 Não apresente as respostas inicialmente.

---

## 6. Revisão espaçada

 Com base no que estudei sobre finanças pessoais, crie uma nova sessão de revisão.

 Priorize conceitos que:

 * apresentei dificuldade;
 * são fundamentais para compreender outros conceitos;
 * possuem relação entre si.
